# Бот дежурств в столовой

## Настройка токена

1. Используйте Python 3.10 и окружение `.venv` (код рассчитан на aiogram 2.25.1).
   Создайте окружение: `py -3.10 -m venv .venv`.
   Установите зависимости: `.\.venv\Scripts\python.exe -m pip install -r requirments.txt`.
2. Создайте `.env` рядом с `config.py`, скопировав `.env.example` (если `.env` ещё нет).
3. Впишите новый токен из BotFather в `.env`:

   ```dotenv
   BOT_TOKEN=ваш_новый_токен
   ```

4. Запустите или перезапустите бота: `.\.venv\Scripts\python.exe app.py`.

`.env` исключён из Git; не публикуйте его и не вставляйте токен в исходный код.
`config.py` загружает `.env` из папки проекта независимо от текущей рабочей
директории. На сервере можно задать переменную окружения `BOT_TOKEN`: она имеет
приоритет над значением в `.env`.

Если токен ранее попал в коммиты, его нужно отозвать через BotFather:
изменение исходников и `.gitignore` не удаляет секрет из истории Git.
